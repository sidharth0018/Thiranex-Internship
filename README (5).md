# Sales & Revenue Analysis Dashboard 📊

An interactive dashboard to analyze sales and revenue data, track KPIs, and generate business insights — built with Python, Pandas, and Streamlit/Plotly.

## Features
- Import data from CSV (easily extendable to Excel/DB)
- KPI cards: Total Sales, Total Profit, Orders, Avg Order Value
- Monthly revenue trend line chart
- Top 10 products by sales
- Sales share by region (pie chart)
- Category-wise sales vs profit comparison
- Interactive filters: Region, Category, Date Range

## Tech Stack
Python · Pandas · Streamlit · Plotly

## Project Structure

sales-revenue-dashboard/

## Run Locally
```bash
pip install -r requirements.txt
cd dashboard
streamlit run app.py
```

## Key Insights (sample)
- Revenue shows seasonal spikes across months
- Electronics and Furniture categories drive the highest profit margins
- Top 10 products contribute a disproportionate share of total sales
